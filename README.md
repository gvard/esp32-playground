# esp32-playground

**A collection of modular ESP32 projects and experiments, specifically tailored for compact ESP32-S3 development boards featuring integrated displays, Wi-Fi, and Bluetooth (LilyGO T-QT series and similar devices).**

This repository contains ready-to-use code, visual dashboards, and specialized network utilities implemented in both **Arduino IDE (C++)** and **MicroPython**. These include real-time Wi-Fi RSSI monitors and firmware that transmits Art-Net/DMX packets to a transparent controller for circular dome LED lighting. 

*Note: The light programs and scripts for the planetarium dome are located in a separate repository: [planetarium-led](https://github.com/gvard/planetarium-led).*
